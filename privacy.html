Privacy Policy: Pilumo Uploader

Last updated: 22 November 2026

Who this applies to

Pilumo Uploader is a private tool used only by the owner of the Pilumo YouTube channel to upload and manage that channel's own videos. It has no other users.

What Google data the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API to:

  • upload videos, captions and thumbnails to the Pilumo channel,
  • set a video's title, description, tags, playlist and publishing time,
  • read basic channel and video details (such as the channel name, video count and a video's status) to confirm an action worked.

How the data is used

The data is used only to perform those actions on the Pilumo channel. It is not sold, shared with third parties, used for advertising, or used to train any AI model.

How the data is stored

The access credentials are stored as encrypted secrets in the channel owner's private GitHub repository and are used only while an upload job runs. The tool keeps a small log of the channel's own video IDs and publishing status. No personal data about viewers is collected.

Removing access

Access can be withdrawn at any time at myaccount.google.com/connections by removing "Pilumo Uploader".

Google API Services User Data Policy

Pilumo Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploaded content is also subject to the YouTube Terms of Service and the Google Privacy Policy.
